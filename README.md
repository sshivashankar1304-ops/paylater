# Pay Later Travel ✈️

A modern, responsive recreation and enhancement of [PayLaterTravel.com](https://www.paylatertravel.com) featuring:
- **0% Interest Layaway Flights**: Lock in today's best flight fares with a small deposit (as low as $25 to 10%) and pay the rest in up to 18 weekly installments.
- **Official Underwriting & Eligibility Portal**: Multi-step identity, banking, and employment assessment with email outcome notifications.
- **Downloadable Application PDF**: Instant generation of official printable application summary documents.
- **Flight Search & Results Engine**: Real-time autocomplete and simulated flight schedules with deposit calculations.
- **Multi-Currency Converter**: Real-time price updates across $USD, $AUD, £GBP, $CAD, and $NZD.
- **Interactive Live Support Chat**: Responsive assistant drawer answering common layaway questions.
- **Admin Inquiries Dashboard**: Zero-backend submission storage with instant one-click CSV/Excel export.
- **Vercel Ready**: Preconfigured with `vercel.json` and `api/submit.js` for instant global deployment.

## 📦 How to Run Locally

You can simply open `index.html` in any modern web browser or start a local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Open in browser:
http://localhost:3000
```

---

## 🚢 Deploying to Vercel

1. Push to GitHub (already configured).
2. Go to [Vercel](https://vercel.com) and import the repository `paylater`.
3. Framework Preset: **Other** / Static Site.
4. Click **Deploy**!
